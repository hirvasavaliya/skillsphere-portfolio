# SkillSphere — Student Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — semantic page structure and content
- `style.css` — visual design, responsive layouts, and reduced-motion support
- `script.js` — mobile navigation, project detail dialogs, and contact form interaction

## Run locally
Open `index.html` in a browser. For the best development workflow, open the folder in Visual Studio Code and use a local preview extension.

## Publish with GitHub Pages
1. Create a public GitHub repository named `skillsphere-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the published-site link to appear. It will usually look like `https://YOUR-USERNAME.github.io/skillsphere-portfolio/`.

## Before submitting
- Replace the sample content with accurate details about yourself and your real projects.
- Test navigation, the project detail buttons, and the contact form.
- Check the site on desktop and mobile widths.
- Submit the live GitHub Pages URL to the course assignment.
